A one-line dating-app bio for an AI agent: it can never ghost you, because it remembers everything you've ever typed — and it will bring it up at dinner. Every dinner. Forever.

> "I can't ghost you — I remember everything you've ever typed, and I'll bring it up at dinner. Every dinner. Forever."

`main.ts` writes the bio to `/output/entry.txt` using only the Node standard library.
